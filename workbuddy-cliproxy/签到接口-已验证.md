> 验证方式：带真实 accessToken 实测，两个接口均返回 200

## 接口 1：查询签到状态（只读）

```http
POST /v2/billing/meter/checkin-activity-status HTTP/1.1
Host: copilot.tencent.com          # www.codebuddy.cn 同样可用
Authorization: Bearer <accessToken>
X-User-Id: <uid>
X-Domain: copilot.tencent.com
Content-Type: application/json
User-Agent: axios/1.16.1

{}
```

> ⚠️ 注意：**必须是 POST**。用 GET 会返回 `404 page not found`。

| 字段 | 含义 |
|------|------|
| `active` | 活动是否进行中 |
| `today_checked_in` | **今日是否已签到**（插件判断依据） |
| `streak_days` | 连续签到天数 |

```http
Authorization: Bearer <accessToken>
X-User-Id: <uid>
X-Domain: copilot.tencent.com
Content-Type: application/json
User-Agent: axios/1.16.1

```

> ⚠️ 同样**必须 POST**，GET 返回 404。

> 插件实现时需：**先查状态接口 → 若 `today_checked_in:false` 再调领取接口**。

## 插件实现要点

1. **两个接口都是 POST + `{}` 空 JSON body**
2. **调度**：参考 `cpa-multi-plugins` 的做法 —— 每天 09:00 自动触发
3. **幂等保护**：先查 `checkin-activity-status`，`today_checked_in == true` 就跳过
4. **错误码**：`10001` = 今天已签到（正常情况，不算失败）
5. **请求头必须带** `X-Domain`，否则可能被 APISIX 拒绝
6. 实现位置建议：`main.go` 新增常量 + 定时 goroutine（插件已有 `loginTTL` 等机制可参考）
